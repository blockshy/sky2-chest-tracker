# 探索辅助测试指南

当前版本为 **0.5.0**。地图全显、统一未到访传送点、地图内即时刷新及对应组合键已获得用户本机测试正常反馈。这些反馈不代表每个地点和所有剧情组合均已逐项验证。本页提供原生菜单探索开关的回归步骤；面板专项检查见 [测试说明](TESTING.md)，独立全传送清单的操作及边界见 [全传送指南](TRAVEL.md)。

探索辅助包含两个独立开关：地图全显、未到访传送点。两者默认关闭，退出游戏后不会保存开关状态，下次启动仍为关闭。

## 测试前准备

1. 将需要保留的进度另存到一个新的存档栏位，保留测试前的副本。
2. 确认加载的是待测试版本的 DLL；当前为 0.5.0，并使用 [安装指南](INSTALLATION.md#兼容版本) 支持的游戏构建。
3. 读取测试存档，在安全、可正常打开原生地图的场景记录当前地图、剧情阶段，以及面板的本周目／继承宝箱计数。
4. 先在两个开关都关闭时观察地图和传送列表，作为对照。

Mod 不把“全显”或“传送点临时开放”写成永久探索／到访标志；实际行走、正常传送、游戏自动保存仍可能按原生规则记录进度。需要比较完全相同的状态时，重新读取测试前存档。关闭 Mod 不会撤销玩家已经实际完成的探索或到访。

## 快捷键

| 功能 | 键盘 | Xbox 手柄 |
| --- | --- | --- |
| 地图全显开／关 | Ctrl + F6 | 按住 View，再按十字键 ↑ |
| 未到访传送点开／关 | Ctrl + F8 | 按住 View，再按十字键 ↓ |

探索行应将名称与状态紧邻显示，例如“地图全显：已关闭”；对应组合键高亮，并与上方宝箱快捷键的右侧按键列对齐。主面板宽度随实际内容和输入方式调整，切换键盘／手柄后仍应完整显示并保持对齐，等待或不可用等状态不得遮挡组合键。

每次组合键只应切换一次，长按不应连续切换。未到访传送点在普通区域地图、全地点列表和城镇／道路子列表的浏览阶段可原地刷新，无需关闭再打开地图。如果正处于确认弹窗或地图转场，刷新会等待回到安全的浏览阶段；此时应先取消确认或等待转场完成。

刷新可能让列表滚动位置恢复默认；当前选中的临时目的地消失时，由原生地图重新选择有效目标。不要把刷新期间选中位置的改变当成传送已经执行。
如果切换后当前子列表或整个传送清单合法为空，地图会沿原生退出动画正常关闭；功能保持可用，可以重新开图后继续切换。

F9／View + RS 仍只暂停或恢复宝箱地图修改，不控制这两个探索开关。要关闭探索辅助，请分别使用上表的快捷键，或退出游戏后重新启动。

## 功能边界

地图全显显示原生已经加载或选中的地图中的未探索分块，保持楼层选择、淡入淡出和脚本禁用限制。它不会把剧情尚未提供的地区加入地图目录，也不保证地图中每一种隐藏图标都出现。未探索分块在开启后没有变化时，先确认当前选择的地图确实存在尚未探索的区域。

未到访传送点自动枚举当前地区的原生传送记录，没有固定点位名单或数量。目的地必须已被游戏登记且最终未被禁用；存在所属地点分组时，该分组也必须属于当前地区且未被禁用。满足条件但尚未到访的点可以临时显示，必要时同时显示其分组，不要求先到访城镇入口或同一道路上的其他节点。原生静态条件、内部点和特殊标识过滤仍然保留，不会把传送表的全部记录直接列出。

此开关采用的是**原生菜单许可**，不等于完整剧情可达判断；可能越过入口剧情、物理障碍或迷宫层级。因此，“正常走路暂时到不了，但原生菜单未禁用”的目的地出现，符合本版本预期。实际确认窗口、传送前后脚本继续由游戏执行，真实到访标志不因临时显示而改写。

## 统一传送范围测试

1. 选用当前地区尚有未到访地点的存档。先在开关关闭时记录原生地图和列表，再保持地图打开并开启未到访传送点。检查普通设施、道路或其他目的地是否按当前原生许可出现；实际数量取决于存档，不以固定数量作为通过标准。首次传送优先选一个熟悉的普通设施。
2. 检查尚未实际进入的城镇或道路：如果原生已登记且最终未禁用，目的地可以显示，不需要额外的到访锚点。若符合条件的点所属分组原先隐藏，分组应同步出现；关闭功能后，未实际到访的点和仅因辅助出现的分组应恢复原状。
3. 在有原生灰态目的地或灰态地点分组的剧情存档中检查负例：开启功能不能使其变成可用。当前原生未登记的点、其他地区的点，以及原生过滤的内部／特殊标识点也不应被加入。没有合适存档时记为未测，不为补齐测试而修改剧情旗标。
4. 分别停留在区域地图、全地点列表、城镇／道路子列表中重复开关。选中临时显示的目标后关闭功能，检查有效选择恢复、没有残留可确认项目；地图镜头和缩放应保持正常。如果当前子列表或整个传送清单合法为空，应正常关图且保持功能可用，重新开图后继续切换应正常。若有普通地图最初没有显示项的场景，也应能处理开启请求；重算后仍无可显示项目时正常关图。列表不应出现开发用名称、重复条目或无效编号。
5. 通过原生确认窗口实际传送到一个新增目的地，检查到达位置、传送前后剧情脚本及退出目标场景的路径。实际传送可能自然登记到访，复查临时显示时应重新读取测试前副本。记录具体目的地和剧情阶段，不将单个落点正常视为全地图均已验证。
6. 切换地图、读取不同章节存档后，再观察开关前后的范围。结果应按当前存档的原生最终状态重新计算，不沿用之前的点或分组。章节切换后，原生重新许可但尚未到访的点可以再次临时出现；开关关闭时应恢复该存档的原生列表。

当前版本在原生状态脚本结束、显示构建开始前统一检查最终状态，不使用单个点登记时的中间结果。尚未覆盖的地点、剧情阶段和菜单状态组合仍需继续补测。

## 地图全显测试

1. 在包含未探索分块的地图打开区域地图，记录隐藏区域的位置。保持角色原地不动，开启地图全显，检查同一区域是否出现。
2. 在原地关闭地图全显，检查未实际探索的部分是否恢复隐藏。若正在地图转场，等待转场结束后再比较。
3. 对照已经探索的区域，检查道路、建筑和地图位置是否保持正常，没有整图消失或明显闪烁。
4. 在多层地图切换楼层，再开关全显。应只显示所选楼层，不应把其他楼层叠在一起；切换过程应保持原生淡入淡出。
5. 在功能开启时正常走进一块此前未探索的区域，再关闭功能。已实际走过的区域应继续显示，未走过的区域应恢复隐藏。
6. 换图、读取另一个存档，再返回测试地图。显示应跟随当前地图及所读存档，不应沿用之前存档的探索状态。

如现有存档附近没有未探索区域，可以先完成已探索地图的显示回归，之后再用合适的存档补测“开启显露／关闭恢复”；不要将没有合适场景当作该项已经通过。

## 普通设施与即时刷新回归

1. 选择尚有普通设施未到访、且当前原生菜单许可该设施的存档。先关闭功能并打开原生地图，记录未出现的设施。卢安的布朗西酒店、拉文努村的月之小道亭可用作设施回归的测试候选，前提是当前存档符合条件。
2. 停留在普通区域地图，开启未到访传送点，检查设施是否直接出现。保持地图打开，再关闭功能：未实际到访的新增设施应恢复原状，原本已经可用的传送点应保持可用。
3. 分别停留在全地点列表、城镇子列表中重复开关，确认列表同步更新。将光标停在一个临时开放的设施上再关闭功能，检查原生选择恢复到有效目标，没有残留的可确认项目、崩溃或卡住。
4. 对新增设施打开游戏原生传送确认弹窗，然后关闭辅助功能。刷新应先等待；取消确认返回浏览阶段后，检查该未到访设施消失。首次验证先取消弹窗，不执行传送。地图转场期间切换时，同样应在返回安全浏览阶段后按最后的开关状态刷新。
5. 在地图打开时连续开、关、开，检查最终列表与最后一次开关状态一致，旧列表项没有重复、残留或闪烁。列表滚动位置重置属于已知行为。
6. 再次开启，选择一个候选设施，通过游戏原生确认流程正常传送。核对目标建筑、入口位置及离开建筑的路径。完成实际传送后关闭功能；如果游戏已正常登记到访，该设施继续可用属于预期。需要复查临时开放时，请重新读取测试前副本。
7. 在合适的剧情存档中检查最终灰态禁用点，尤其是剧情封锁期间的柏斯超市；同时检查所属分组被禁用或原生未登记的设施。即使曾经实际到访，也不得因本功能解除这些限制。
8. 如有章节切换后到访记录被清空的存档，先关闭功能核对真实到访状态，再开启功能核对当前原生菜单许可。历史到访不应被写回；当前许可的未到访设施临时出现属于预期。没有此类存档时，将该项记为未测试。

不需要为了测试而强行推进大量剧情或覆盖原进度。不同剧情阶段、城市及地图入口尚需逐步验证，保留原生禁用和传送脚本不能代替全流程实测。

## 键盘、手柄与原功能回归

| 操作 | 预期结果 |
| --- | --- |
| Ctrl + F6、Ctrl + F8 各按两次 | 对应开关先开启再关闭；不同时触发普通 F6／F8 功能 |
| View + ↑、View + ↓，分别尝试长按 | 每次按下只切换一次；不同时触发地图光标移动或其他原生动作 |
| 先松 View，以及先松十字键 | 两种松键顺序都不产生额外动作，全部松开后原生输入恢复 |
| 单独短按 View、单独使用十字键 | 保持游戏原来的用途 |
| 键盘操作后改用手柄，再切回键盘 | 面板提示随设备切换，功能状态保持一致 |
| 松开按键后断开、重连手柄 | 重连后组合键可用，不产生意外切换或卡键 |
| 组合键按住期间断开手柄，再重连 | 不应补发切换或残留输入；松开后重新操作可用 |
| 切到其他窗口再切回游戏 | 后台输入不误切换；回到游戏后按键正常 |
| F9／View + RS 暂停、恢复宝箱修改 | 探索开关不随之改变；宝箱功能按原用途切换 |
| F8 清单、F10 筛选、翻页、模式切换 | 原有宝箱功能正常；清单页码位于顶部统计行右端，底部快捷键分两行且完整高亮，手柄组合逐项带 View 前缀；面板收窄后长路径、计数和提示仍无裁切或重叠 |

只开关探索功能、停在原地且不开启宝箱时，本周目和继承记录的宝箱计数应与测试前一致。

## 重启及保存对照

完成测试后正常退出游戏，再启动并读取测试前副本：两个探索开关应均为关闭，地图和传送列表应按该存档的真实状态显示。另读实际行走／传送后保存的测试进度，确认游戏自然登记的探索和到访仍可正常恢复。不要把这两类存档混作同一对照。

## 反馈内容

如果切换后地图自动关闭，且面板把未到访传送点标为“不可用”，表示本次刷新未通过结构校验，已停止继续修改菜单。记录当时所在的列表层级和操作步骤，并保留日志；这不属于正常即时刷新的预期结果。

请记录 Mod 版本、游戏构建、地图／城镇、剧情章节、输入设备、功能开关状态、操作步骤，以及实际与预期结果。注明未具备场景而跳过的项目。出现异常时，保留 `Sky2ChestTracker` 下与操作时间对应的日志片段；公开反馈前移除个人信息，无需上传完整存档或内存快照。
