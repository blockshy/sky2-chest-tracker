# 安装、更新与卸载

[项目首页](../README.md) · [操作说明](USAGE.md) · [全传送与精确返程](TRAVEL.md)

```powershell
Get-FileHash -LiteralPath '你的游戏安装目录\sora_2nd.exe' -Algorithm SHA256
```

## 开始前

1. 获取并完整解压 `Sky2ChestTracker-0.5.0.zip`。公开安装包见 [Releases](https://github.com/blockshy/sky2-chest-tracker/releases)；GitHub 自动生成的 **Source code** 压缩包只有源码，不能直接安装。
2. 保存所需进度并正常退出游戏。安装、更新和卸载均在游戏退出后进行。
3. 找到包含 `sora_2nd.exe` 的游戏根目录。下文命令中的“你的游戏安装目录”均替换为这个路径。
4. 如果根目录已有来源不明的 `xinput1_4.dll`，停止操作，不直接替换或删除；先阅读[与其他 Mod 共存](#与其他-mod-共存)。已安装本 Mod 时，按更新步骤处理。

安装器只将 Mod DLL、安装记录和必要的许可文件写入游戏目录。安装包内的玩家指南和脚本资料不安装到游戏目录，构建和开发资料保留在仓库。

## 脚本安装、更新与卸载

### 脚本安装

在完整解压的安装包目录打开 PowerShell，运行：

```powershell
.\Install-Mod.ps1 -GamePath '你的游戏安装目录'
```

脚本检查游戏版本、安装包和文件归属，并校验安装后的 DLL。成功后从 Steam 正常启动游戏，左上角应显示“宝箱追踪 · 0.5.0”。

### 脚本更新

退出游戏，完整解压新版安装包，再运行新版的同一条安装命令。必须更新 DLL 才能获得新功能，只替换脚本不会更新 Mod。

脚本先用现有安装记录与 SHA-256 核对旧 DLL，备份至新安装包目录下的 `backups/` 并校验备份，再执行更新。脚本备份的是旧 DLL；如需手动回退，请另行保留与它配套的旧 `Sky2ChestTracker/install.json`，回退时两者一起恢复。

若游戏目录遗留旧版说明文件，安装器只将内容哈希与已知版本一致的六份旧文档移至安装包的 `backups/legacy-docs-…/`。修改过的文档、未知文件及链接会保留，不递归清理目录；已安装相同 DLL 时也可运行安装器完成这项整理。

### 脚本卸载

退出游戏，在安装包目录运行：

```powershell
.\Uninstall-Mod.ps1 -GamePath '你的游戏安装目录'
```

脚本只删除经安装记录和实际哈希核对属于本 Mod 的 `xinput1_4.dll`，保留游戏存档、返程文件、日志和其他文件，不删除整个目录。若 DLL 已被其他 Mod 替换或记录不匹配，会停止删除。

### 先预演，不改文件

安装和卸载均支持 `-WhatIf`，会检查版本或文件归属等适用条件，在复制、备份或删除前停止：

```powershell
.\Install-Mod.ps1 -GamePath '你的游戏安装目录' -WhatIf
.\Uninstall-Mod.ps1 -GamePath '你的游戏安装目录' -WhatIf
```

预演不等于游戏内兼容测试。收到冲突提示后，先确认现有文件来源；不要同时运行其他安装器或文件替换工具。若脚本被 PowerShell 执行策略阻止，可按设备管理规则处理，或使用下方手动方式；本项目不会自动修改系统执行策略。

## 手动安装、更新与卸载

### 手动安装

1. 按[开始前](#开始前)完成解压、退出游戏和版本核对。根目录已有来源不明的同名 DLL 时，不选择“替换”。
2. 将安装包 **`dist` 内的 `xinput1_4.dll` 和 `Sky2ChestTracker` 文件夹**一起复制到游戏根目录。不要把 `dist` 本身复制进去。
3. `dist/manifest.json` 和 `dist/legacy-documents.json` 是脚本资料，无需手动复制；玩家指南也不需要复制到游戏目录。
4. 从 Steam 启动游戏，确认面板显示“宝箱追踪 · 0.5.0”。

必要结构如下：

```text
游戏根目录/
├─ sora_2nd.exe
├─ xinput1_4.dll
└─ Sky2ChestTracker/
   ├─ install.json
   ├─ LICENSE
   ├─ THIRD_PARTY_NOTICES.md
   └─ licenses/
```

`install.json` 是该安装包 DLL 的配套归属记录，必须一并复制。它不包含个人路径或存档信息；许可证也应保留。

### 更新或卸载前：核对 DLL 归属

在 PowerShell 中运行以下只读查询，也可以使用其他工具的 SHA-256 校验功能：

```powershell
Get-FileHash -LiteralPath '你的游戏安装目录\xinput1_4.dll' -Algorithm SHA256
```

打开现有 `Sky2ChestTracker/install.json`，确认 `product` 为 `Sky2ChestTracker`，且 `dll_sha256` 与查询结果一致，比较时忽略字母大小写。缺少记录、记录损坏、哈希不一致或来源不明时停止，不凭文件名判断归属。

### 手动更新

1. 保存进度并退出游戏，完整解压新版安装包，按上方方法核对现有 DLL。
2. 将当前 DLL 和配套 `install.json` 备份到游戏目录外。
3. 将新版 `dist` 中的 DLL 与 `Sky2ChestTracker` 文件夹一起复制到游戏根目录，只替换本 Mod 对应文件。保留日志、返程文件、用户文件和其他 Mod 文件，不先删除整个目录。
4. 启动游戏验证。需要回退时，配套还原旧 DLL 和旧安装记录，不能只还原其中一个。

### 手动卸载

1. 保存进度并退出游戏，按上方方法核对当前 DLL 确实属于本 Mod。
2. 只移走或删除游戏根目录中经核对的 `xinput1_4.dll`。若文件被其他 Mod 替换或核对不通过，停止删除。
3. 保留 `Sky2ChestTracker` 文件夹中的返程记录、日志和许可证；它们不会加载 Mod，也不会影响存档。

手动复制或删除没有脚本的自动保护，需要自行核对。不要修改 `dll_sha256` 来通过检查，也不要把本 Mod 的记录套用到其他 DLL。

## 手动与脚本混用

| 操作顺序 | 结果与要求 |
| --- | --- |
| 完整手动安装 → 脚本卸载或更新 | 支持；脚本重新核对配套记录和当前 DLL 哈希 |
| 脚本安装 → 完整手动更新 → 脚本卸载 | 支持；手动更新必须同时复制新版 DLL 和新版记录 |
| 只手动复制 DLL，缺少记录 | 脚本拒绝覆盖或卸载，不猜测归属 |
| 只更新 DLL，仍保留旧记录 | 哈希不一致时停止；恢复配套 DLL 与记录后再操作 |
| 安装后 DLL 被其他 Mod 替换 | 脚本停止，保留当前文件 |
| 手动移走本 Mod DLL 后再次脚本安装 | 残留安装记录有效时支持，不清理目录内用户文件 |

无 DLL 但已有非空 `Sky2ChestTracker` 目录时，脚本仍要求有效的本 Mod 记录；不会接管来源不明的目录。

## 与其他 Mod 共存

**两个都需要占用游戏根目录 `xinput1_4.dll` 的 Mod，目前不能直接同时安装。**本 Mod 只转发到 Windows 系统 XInput，没有加载第二份 Mod DLL 的串联功能。直接改名不会自动建立加载关系，不应覆盖未知 DLL 或改名尝试共存。

| 现有文件情况 | 脚本行为 |
| --- | --- |
| 同名 DLL 没有本 Mod 的配套记录 | 停止安装或卸载，保留原文件 |
| DLL 与记录的哈希不一致 | 停止，保留当前文件 |
| 记录损坏、字段无效或产品不匹配 | 停止，不根据文件名认领 DLL |
| DLL、记录或 Mod 目录是链接／重解析点 | 停止，要求先核对实际位置 |
| DLL 经记录和实际哈希核对属于本 Mod | 可以更新或卸载；更新前保存并校验旧 DLL 备份 |
| 其他 Mod 使用不同 DLL 名或只替换资源 | 没有同名文件冲突，仍需验证游戏内兼容性 |

其他 Mod 可能同时修改地图、手柄输入、窗口消息或图形绘制，不能只凭文件名判定兼容。本项目没有通用的其他 Mod 检测器，也没有经验证的第三方 Mod 兼容清单。遇到问题可分别单独运行，再提供两个 Mod 的名称、版本、文件名和日志。

脚本会在实际覆盖或删除前再次核对 DLL，但检查与操作对所有外部程序并非原子操作。不要并行运行多个安装器或文件替换工具；脚本不能保证其他程序同时改动目录时仍完全避免冲突。

## 保留哪些文件

| 文件或目录 | 用途与保留要求 |
| --- | --- |
| `Sky2ChestTracker/install.json` | DLL 归属记录；必须与对应版本 DLL 配套，不手改哈希 |
| `Sky2ChestTracker/revisit-return.dat` | 最近的出发点，使用全传送后生成 |
| `Sky2ChestTracker/revisit-history/` | 历次返程记录，更新、卸载和转移游戏时保留 |
| `Sky2ChestTracker/tracker.log` | 运行后生成的诊断日志 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`licenses/` | 保留 Mod 目录内的许可证与第三方声明 |

返程文件不绑定存档栏位，也不保存整份游戏进度，具体用法见[全传送与精确返程](TRAVEL.md)。卸载或更换 DLL 不会撤销游戏已经保存的剧情、道具或宝箱变化。
