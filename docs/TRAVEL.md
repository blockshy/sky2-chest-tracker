# 全传送与精确返程

[项目首页](../README.md) · [安装、更新与卸载](INSTALLATION.md) · [宝箱、探索与手柄使用](USAGE.md)

全传送清单包含 **155 个原生地点、迷途之森补箱入口和 1 项精确返程，共 157 项、16 页**。可以跨地区前往尚未到访或正常流程已无法进入的地点，再返回首次出发时的位置与朝向。清单内的地点不受章节、剧情完成或到访记录限制，11 个纯内部入口不展示。

这是 Mod 的独立清单，与 [探索辅助](USAGE.md#探索辅助) 中的“未到访传送点”开关分开使用。后者只补显游戏原生菜单当前允许的地点，不影响本清单的范围。

## 前往与返回

1. 在自由行动时打开游戏的**区域地图**，退出地图内的确认弹窗，等待动画结束。
2. 按 `Ctrl + F10` 或 `View + 十字键 ←` 打开全传送清单，选择目的地。
3. 按一次 `Ctrl + F7` 或 `View + 十字键 →`，核对提示中的目标；松开后在 **8 秒内再次按下**相同组合，提交传送。
4. 到达后可以继续前往其他地点。需要返回时，在末页选择**“返回记录的出发点”**，核对地点和时间，确认属于当前存档，再以相同方式两次确认。

首次出发前会保存真实站位与朝向，记录写入失败则不会传送。同一趟内连续从 A 前往 B、C，精确返程仍回到 A；在途中步行通过普通出口也不覆盖 A。返程确认到达后，下一次出发才建立新的起点。

传送只在能稳定浏览游戏区域地图的自由行动状态提交。战斗、对话、演出、加载中，或者当前站位无法可靠记录时，面板会说明原因。长按确认不会代替第二次按下；换目标、翻页、切换历史、收起清单或隐藏面板都会取消待确认操作。

## 快捷键

| 功能 | 键盘 | Xbox 手柄 |
| --- | --- | --- |
| 打开／收起全传送清单 | Ctrl + F10 | View + 十字键 ← |
| 上一页 | PgUp | View + LB |
| 下一页 | PgDn | View + RB |
| 上一个目的地 | Ctrl + PgUp | View + LT |
| 下一个目的地 | Ctrl + PgDn | View + RT |
| 确认前往／返回 | Ctrl + F7 | View + 十字键 → |
| 返程行切换历史记录 | F10 | View + Y |

先按住 View，再按功能键。LB／RB 是肩键，LT／RT 是扳机。翻页与宝箱清单一致，每次移动相邻一页，首末页不循环；逐项选择可自动跨页，长按不连续移动。手柄与键盘提示随输入设备切换，通用操作见 [手柄与输入切换](USAGE.md#手柄与输入切换)。

历史切换只在没有活动行程、且存在多个返程候选时生效。本次行程进行中始终保留最初点，不切换成另一趟的记录。

## 清单位置记忆

宝箱页码与传送选中项分别记忆。关闭清单、隐藏主面板或切到另一份清单后，重新打开恢复各自的位置；传送清单首次打开时，需恢复返程的场景优先选中返程，否则选第一项。

宝箱数据暂时不可用时保留页码，恢复有效数据后按实际页数校正。条目减少或布局变化导致页码越界时，退至最后有效页；切换宝箱显示模式或遗漏筛选仍回第一页。

这些导航状态仅保存在进程内，重启后清除，不写文件或存档，也不保证读档后必然清除。保留选择不代表保留确认：重新打开后，传送仍须重新两次确认。

## 返程记录与重启

旧 0.6.0 ASI 使用过的 `Sky2Mods/Sky2ChestTracker/` 需按 [ASI 迁移说明](ASI_LOADER.md#安装前与旧版迁移) 移到新路径；这是同一分发的数据迁移，不导入独立版历史。

游戏目录中保存以下文件，请在手动更新、卸载或转移游戏时保留：

| 分发方式 | 相对游戏根目录的数据目录 |
| --- | --- |
| 独立版（含 0.5.0 正式版） | `Sky2ChestTracker/` |
| ASI 插件版（当前 0.6.0 包） | `plugins/Sky2ChestTracker/` |

```text
<当前分发的数据目录>/
├─ revisit-return.dat
└─ revisit-history/
   └─ <记录编号>.dat
```

`revisit-return.dat` 保存最近的出发点，`revisit-history/` 保留历次出发记录。脚本更新和卸载会保留它们；手动操作不要删除整个 Mod 文件夹。这些文件只记录返程所需的位置等信息，不保存队伍、道具或任务，也不能回滚游戏进度。

**两种分发不共享返程历史。**插件首次使用空记录，不读取、导入或复制独立版的旧历史；更新插件会保留插件自身记录。首次切换前先用旧版本完成返程并保存，或使用位于正常流程地点的存档。若仍在回访地图，保留原版本完成返程后再换，插件空记录无法恢复原出发点。详细步骤见 [ASI 指南](ASI_LOADER.md)。

**记录不绑定存档栏位。**重启并读取存档后，打开全传送清单末页，核对地点和时间，确认属于当前存档；若有多个候选，用 `F10` 或 `View + Y` 选择正确记录，再两次确认。最新记录未必属于刚读取的存档，Mod 不会自动传送。

同一进程内读取同章节的另一份存档无法可靠识别。**切档前先精确返程，或正常退出重启后再读档。**换到另一章节会结束旧活动行程；返回历史位置也不会恢复当时的任务或剧情状态。

- **迷途之森：**在洛连特分组选择“神秘森林・迷途之森 / 补箱入口”。有 1 个宝箱、没有普通步行出口，须使用记录返程；底图只有简略矩形。建议首次进入后先确认可返程，再探索开箱。

## 使用边界

全传送可以越过原有剧情门槛，但不会补写剧情完成记录或回退章节。**原生剧情、战斗、交互和自动保存仍会运行**，建议前往不同进度的地点前保留独立存档；卸载或换回旧 DLL 不能撤销游戏已保存的变化。

Mod 对已审查的序章、荣耀号特殊宝箱及迷途之森谜题提供限定回访保护，保留奖励与宝箱记录；其他事件没有被全局禁用。该行程保护在精确返程或换章后结束，重启不会仅凭历史记录恢复。读取早期森林等特殊场景的存档时，原生事件仍可能执行，返程记录不等于完整的剧情保护。

已有一周目末期、二周目前期相关地点与往返的实机反馈，不能代表全部地点、章节与任务组合均已逐一验证。遇到与当前进度不符的剧情时，返回或读取事先保留的存档。

## 常见问题

- **无法记录当前站位：**尚未开始新行程。先回到稳定的区域地图浏览状态，查看具体提示，不反复提交。
- **传送后一直等待：**如果超过 60 秒仍无法确认到达，Mod 会解除等待锁并保留起点。能够正常浏览地图后可再选择返程；该提示不表示已经核对到达成功。
- **重启后缺少返程记录：**检查是否保留上述两个路径，不要用其他玩家的文件或手改坐标代替。迷途之森没有普通出口，若无法恢复记录，读取正常地区的存档。
- **反馈异常：**附上版本、独立版／ASI 分发类型、目的地、当前章节、操作步骤和完整提示；返程问题补充记录显示的地点与时间、是否切档或重启。日志为对应数据目录下的 `tracker.log`，无需公开整份存档、内存快照或返程文件。
