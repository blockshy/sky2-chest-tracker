## 探针能力边界

`tests/asi/` 中的 `Sky2CoexistProbe.asi` 仅用于开发诊断，不进入玩家安装包，也不是队伍 Mod。它通过 `InitializeASI` 启动幂等工作线程，每约 2 秒记录心跳；仅在宿主处于前台时观察 F11 的新按下，不截获或消费按键，不调用 XInput，没有绘制、窗口消息或游戏函数挂钩。

日志固定写入游戏根目录 `Sky2CoexistProbe/probe.log`，主要字段：

- `InitializeASI worker started`：工作线程已启动。
- `xinput-module=`：实际 XInput 模块路径、版本及产品信息。
- `chest=loaded path=`／`chest=absent`：本次观察到的宝箱模块状态。
- `chest-at-first-entry=`：探针入口调用时宝箱是否已加载，用于佐证顺序。
- `heartbeat=`：持续运行计数。
- `F11 observed; key was not intercepted or consumed.`：前台观察到 F11，未消费该键。

**F11 仅属于诊断流程，不是宝箱 Mod 的玩家快捷键。**探针通过不代表多个界面、同一游戏函数挂钩或同一手柄组合键能够共存。

## 复现隔离加载验证

按 [构建指南](BUILDING.md#准备-loader-与隔离加载验证) 准备固定 UAL 与 Windows x64 测试产物，再运行：

```powershell
# 使用新输出目录；省略 OutputDirectory 时脚本自动建立独立目录，不安装到真实游戏。
.\tests\asi\Invoke-LoaderIntegration.ps1 -LoaderPath '.\.deps\ultimate-asi-loader-9.7.4\xinput1_4.dll' -BinaryDirectory '.\build-release\tests\asi' -ChestPluginPath '.\build-release\Sky2ChestTracker.asi' -StandaloneDllPath '.\build-release\xinput1_4.dll'
```

保留脚本生成的报告、每个场景的日志与二进制哈希。测试通过只证明报告所列场景；不得把假宿主的安全拒绝标为宝箱功能实测通过。

## 实机回归清单

先保留正常流程地点的独立存档，记录旧独立版目录哈希。首次迁移前完成原版本的返程；安装顺序见 [玩家指南](ASI_LOADER.md)。诊断时另将探针放入 `plugins/`，每次增减插件都退出游戏后再操作，不做热卸载。

1. 从 Steam 正常启动并读档，核对 Loader 与宝箱实际加载路径、版本和仅一份面板。
2. 核对宝箱图标、两组计数、清单翻页与探索开关；执行一次传送与精确返程，检查本次出发点和朝向。首次 ASI 历史应为空，旧独立版文件应不变。
3. 从键盘切换到 Xbox 手柄，检查提示、View 短按、View + A／RS、LB／RB 单次翻页及传送组合；断开重连后再次验证。
4. 游戏前台短按 F11，再松开，至少等待两个心跳周期，核对本次启动日志中模块身份、F11 与递增心跳。
5. 正常退出并核对两套数据目录，再分别测试下表组合。日志必须以本次启动时间为准，不能使用旧记录证明当前成功。

| 组合／操作 | 检查重点 | 当前实机覆盖 |
| --- | --- | --- |
| Loader + 宝箱 + 探针 | 两者加载、输入与传送正常、旧数据不变 | 上述本机范围已确认 |
| Loader + 探针 | 无宝箱面板，`chest=absent`，F11／心跳正常 | 隔离验证通过，真实游戏重启待测 |
| Loader + 宝箱 | 原功能正常，探针日志不新增 | 隔离验证通过，探针移除后的真实重启待测 |
| 卸载宝箱，保留探针 | Loader 与探针不被删除 | 安装器验证通过，真实游戏重启待测 |
| 仅保留 Loader | 正常启动，无宝箱面板 | 真实游戏待测 |
| 切回 Standalone | 仅一个入口，使用旧数据目录，插件数据保留 | 文件切换验证通过，真实游戏重启待测 |

## 尚未覆盖与问题记录

其他 Steam Input 设置、其他手柄类型、第三方 ASI 组合及第二个实际界面 Mod 仍需分别验证。未来队伍 Mod 的输入、绘制与剧情逻辑应有自己的共存回归，不能继承本探针的结论。

问题记录应包含版本、二进制哈希、游戏构建、启动组合、输入设置、操作时间、步骤和完整提示。当前插件日志为 `plugins/Sky2ChestTracker/tracker.log`，探针日志为 `Sky2CoexistProbe/probe.log`；独立版日志位于原 `Sky2ChestTracker/tracker.log`。确认使用对应本次运行的日志，避免混用旧版证据。
