# ASI 加载验证

[项目首页](../README.md) · [手动安装](INSTALLATION.md) · [测试总览](TESTING.md)

当前二进制的测试状态见 [Ver.1.05 兼容性记录](GAME_1_5_0_COMPATIBILITY.md)。测试目录中的诊断探针仅用于隔离加载验证，不放入玩家安装包。

## 隔离宿主的覆盖

测试使用核验过的 Ultimate ASI Loader 9.7.4 x64、独立临时目录和模拟宿主。主要检查：

- Loader 入口与 XInput 系统转发。
- ASI 初始化顺序、缺少插件与移除插件后的行为。
- 相同宝箱模块的重复初始化保护。
- 生产 DLL／ASI 遇到不支持的宿主 EXE 时安全停止挂钩。
- 独立版与插件版的运行数据路径隔离。

探针只能证明加载、心跳和前台输入观察，不能证明两个实际 Mod 的绘制、输入拦截或相同函数挂钩兼容。

## 手动实机检查

1. 退出游戏，备份后移走其他 Mod，保留公共 Loader 与一份 `Sky2ChestTracker.asi`。
2. 从 Steam 启动，确认只有一份面板，并核对本次日志中的版本、加载路径和各模块就绪信息。
3. 按 [测试总览](TESTING.md#游戏内检查) 检查宝箱、探索、手柄、传送和精确返程。
4. 正常退出后核对日志、新返程记录及旧数据备份；避免把上次启动的成功记录计入本轮。

若将来验证其他 Mod 共存，每次只加入一个插件，并记录其版本、实际加载路径和具体功能组合。单独运行成功后加入其他插件出现问题，应分别回退定位，而不是覆盖 Loader 或关闭版本校验。
