`Ver.1.05` 是游戏标题界面的编号，`1.5.0.0` 是 Windows 文件属性中的编号，两者对应同一游戏构建。Mod 按完整 EXE 指纹识别版本，不对未知构建启用挂钩。0.6.1 仅适用于 Ver.1.04。

## 功能与记录

- 支持宝箱追踪、本周目与继承记录、地图全显、未到访传送点、键盘与 Xbox 手柄操作。
- 支持全传送清单、迷途之森入口与精确返程，迷途之森回访保护保留正常地图和宝箱交互。
- 保留 59 个地图分组、566 个宝箱及八种文字语言的界面与地点名称。
- 当前返程记录使用 `revisit-return-26290169.dat` 与 `revisit-history-26290169/`。旧构建记录原样保留，不跨游戏版本执行，也不能通过改名或修改指纹继续使用。

## 验证范围

通过 **29 组 CTest、89 项 Python 测试、10 个 UAL 隔离场景**，覆盖核心逻辑、版本识别、原生接口校验、加载与历史文件保留。

ASI 版已验证宝箱界面、记录切换、地图辅助、手柄操作、普通传送、迷途之森入口及精确返程。独立版通过构建与隔离转发测试。

未逐一验证全部地点、章节、宝箱、八语界面、手柄布局和其他 Mod 组合；上述范围不代表任意游戏流程或多 Mod 组合均已验证。
