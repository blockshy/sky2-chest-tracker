# 游戏 1.4.0 兼容性验证

本次适配从已发布的 `v0.6.0`（`6cc5911`）开始。原 main 的两个未发布提交和 30 个未提交文件已保存到 `dev` 的 `6264d67`，并推送至 GitHub。本文描述兼容性开发构建，不代表现有 0.6.0 Release 附件已被替换。

## 游戏版本与故障原因

| 项目 | 0.6.0 原适配版本 | 本次目标 |
| --- | --- | --- |
| EXE 文件版本 | 1.3.2.0 | 1.4.0.0 |
| Steam build | 25386012 | 25721473 |
| EXE 字节数 | 13,464,576 | 13,470,208 |
| SHA-256 | `d8b2911d1576216bdc22d070550e4f531e105de7ed2981885849669f4acf8aaf` | `cab62e5872222efb2aaf272be47f14263db4e7132ad7df5255db8efbee9959ea` |

旧 Mod 在完整 EXE 哈希不匹配时跳过所有挂钩。新版 EXE 同时移动了代码、全局数据和虚表，解除哈希检查会使用错误地址，因此本次逐项更新原生适配，继续拒绝未知 EXE。

`native/game_version.h` 是资源生成、构建、运行时和安装包的共同版本来源。直接调用 CMake 时，编译期断言也会拒绝旧目录与新地址混配。打包脚本检查 Mod 二进制包含当前版本指纹，防止误将旧二进制标注为新版兼容。

## 静态验证

使用本机保留的完整旧 EXE 与更新后的 EXE 比较，不把统一地址增量或函数开头几字节相同作为充分证据。函数对照保留寄存器、普通字段偏移、常数和分支结构；地址重定位另外核对调用目标、RIP 引用、导入或 RTTI 身份。

| 路径 | 核验结果 |
| --- | --- |
| 宝箱图标 | `TBoxBehavior` RTTI 及虚表第 9 槽确认；对象图标函数 `2C6BC0 → 2C7200`，区域地图函数 `3DD0E0 → 3DD930`，完整指令对照一致 |
| 公共对象 | 表管理器 `C5D778 → C5DC88`，场景管理器 `C60E08 → C61318`，保存旗标 `C60E58 → C61368`，由多个实际 RIP 引用交叉核验 |
| 手柄输入 | 唯一调用 `6A55A8 → 6A63B8`；IAT `8BB6E8 → 8BB6F0`，仍为 `XINPUT1_4.dll` 序号 2；完整输入函数一致 |
| 语言 | 设置全局 `C60E50 → C61360`；对象内文本语言 `+623A31` 保持不变，原生读取、写回和八语枚举分别核验 |
| 地图全显与菜单刷新 | 18 个入口或调用段独立匹配，14 个安装签名直接比对新版 PE；4 个菜单虚表分别通过 RTTI 定位，并非统一平移 |
| 传送、返程、特殊箱与森林 | 包含异常展开链分段在内的原生函数对照；落地加载大函数有日志行号变化，相关对象字段、参数和调用链保持一致 |

资源重新从新版游戏提取并比较：

- 宝箱表 571 行的身份、参数及旗标覆盖保持一致；566 个正式宝箱、59 个地图分组不变。
- 一个宝箱场景模型由 `ob_s04_010` 改为 `ob_s04_011`，其身份、位置及收集旗标不变。
- 180 条传送目录记录完整一致；新版部分外语名称修订已随资源重新生成。
- `system.dat` 文件整体发生变化，传送前后脚本、地图重建、特殊箱及事件盒启用相关 7 个函数逐函数比较一致。
- 迷途之森相关两个脚本共 620 个函数中，仅一条 NPC 台词所在函数变化，初始化和机关保护相关函数保持一致。

返程记录写入当前游戏指纹，并按 Steam build 使用 `revisit-return-25721473.dat` 和 `revisit-history-25721473/`。旧无后缀文件原样保留，不作为新版可执行返程记录，也不会阻止新版保存新的出发点。

## 实机结果与日志审查

实机使用原生 Direct3D 11 与固定的 UAL 9.7.4；按用户要求移出其他 Mod，只加载本次宝箱插件。原插件、其他 Mod、运行数据和用户存档在测试前已备份。游戏界面显示 `Ver.1.04`，EXE 文件版本为 `1.4.0.0`。安装的 ASI SHA-256 为 `c967b646016a6ac49a8b4ca0b5c53d4fb90748da3f855810cabf969ca3fabfc5`。

用户手动完成测试并反馈功能均正常；助手核对日志，未向游戏发送并行操作。本轮修复版启动从原始日志第 222 行开始，共审查 109 行，包含 `Validated game 1.4.0.0 (Steam build 25721473)`；前面的三条 `Unsupported executable` 属于修复前运行，不是本轮失败。
