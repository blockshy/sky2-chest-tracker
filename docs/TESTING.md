安装器测试在 `build-installer-tests/` 下创建并清理独立合成目录，执行真实安装／卸载脚本。
只替代 EXE 版本识别和游戏进程查询；DLL 哈希、记录解析及文件操作均真实执行。

这些测试不证明第三方 Mod 的运行时兼容，也不覆盖其他程序并发替换文件的情况。

旧文档输入固定保存在 `tests/fixtures/legacy-0.3.2/`，不随当前开发文档更新，也不进入玩家安装包。
混用测试包含完整手动安装后的脚本更新／卸载、手动更新后记录匹配与不匹配、只复制 DLL、模板记录旁的外来 DLL，以及手动移走 DLL 后重新安装。

## 0.3.3 缩放验证

PR #1 的完整 DLL 已通过用户游戏内实测，反馈正常；正式版在该实现上更新版本显示和发布说明。
本地还直接运行该面板的 D3D11 离屏绘制路径，在 1280×720、1920×1080、2560×1440、3840×2160、
3440×1440、5120×1440、1280×1024 及切回 1920×1080 时，检查了面板边界、帧缓冲缩放、真实像素输出和后缓冲释放。
离屏验证使用 WARP，不代表所有显卡驱动、第三方注入工具或 Windows DPI 组合均已验证。

## 0.3.2 起的实机验证范围

在 README 指定的 Steam EXE、原生 D3D11 和 Xbox ABXY 布局下，已确认：

- 游戏正常启动、中文面板、区域地图中的未发现宝箱标记。
- 本周目与继承记录的计数和图标切换，读取存档后的状态回退。
- 完整地图前缀、两组地区计数、清单遗漏筛选与分页。
- View + RS 暂停／恢复有效且不弹出 Xbox 窗口。
- 组合键不会同时触发已验证场景中的原生操作，单独 View 保留原用途。
- 键鼠／手柄提示热切换、手柄断开重连。

尚未逐箱走访全部目标，未全面测试所有章节、楼层、其他手柄、自定义键盘模拟布局及其他图形注入工具。
成就是否解锁以游戏自身规则为准。

## 修改后的验证建议

输入修改重点检查单按、长按、先松修饰键、先松功能键及前后台切换；测试时确认使用的确实是新 DLL。
统计修改重点检查同一箱“本周目未开但继承已开”的情况，以及读旧档后能否回退。
绘制修改检查中文、完整路径、小窗口换行、页脚和两组地区计数是否完整可见。

报告问题时给出版本、EXE 哈希、设备布局和操作步骤。日志只需附与问题相关的几行，并删去不希望公开的信息。
