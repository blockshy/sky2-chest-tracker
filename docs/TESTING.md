## 0.6.0 八语验证范围

八语构建通过 **29 组 CTest 和 75 项公开 Python 测试**。新测试包括八种游戏文字语言的一一映射、异常内存读取、84 条界面文案共 672 项翻译及格式参数，以及名称生成边界。原生资源核对覆盖每种语言的 616 条地点、180 条传送记录；显示名称覆盖 59 个宝箱地图分组、156 个传送地点和 9 个地区，没有跨语言回退。

本次双分发二进制另通过 **10 个真实 UAL 隔离场景**。三个实际 ZIP 的载荷、清单、SHA-256、许可、文档与脚本编码均核验；**16 次真实安装器操作**覆盖旧精简版 0.6.0 手动安装后的更新／卸载、新版手动与脚本混用、重复安装及预期冲突拒绝。合成游戏目录中的返程记录、历史、其他插件和公共 Loader 按归属保留，每包仍仅安装两份载荷文件。

界面使用实际 ImGui／DX11 绘制路径做离屏检查，覆盖八语、键盘／Xbox 提示、1280×720 与 1920×1080、全部宝箱页与传送页、返程历史及等待状态；检查文本边界、列间重叠、字形与切换后的清单记忆。离屏检查不等于游戏内切换语言或真实传送已经逐项验证。

字体检查另模拟仅有日文字体、仅有 Windows 拉丁／符号字体，以及仅有基础拉丁字体的环境，按实际文案和原生名称检查字形。不能以“能加载一个中日韩字体文件”代替八语完整性；例如只有日文字体时，应提示缺失的简体或繁体字，而英文原生地点中的圈号由符号字体补充。返程名称另覆盖多条道路共用场景、站位地点精确匹配及多个入口共用地点编号，禁止把同场景第一条道路当成出发点。

本机 ASI 版安装后，用户已反馈语言切换测试正常；该反馈没有逐一列出所测语言，不能扩大为全部八语、所有地点的实机验证。后续完整回归应在游戏设置确认文字语言，分别检查主面板、宝箱清单、全传送清单和返程提示，核对原生地点名、长文本和按键提示。单独改变语音不应切换 Mod 文本，临时读不到设置对象时应保留上次语言。实际切换方式和 Windows 补充字体说明见 [语言与字体](USAGE.md#语言与字体)，检测依据见 [语言与原生名称](LOCALIZATION.md)。

此前插件化测试构建在本机 Steam 启动已验证宝箱与诊断探针同时加载、面板和清单、键鼠／Xbox 手柄热切换与重连、一次传送与精确返程。首次插件历史为空，运行后新日志和返程文件写入新目录，旧独立版数据保持不变。当前实机结果来自该测试构建；正式标识构建沿用相同功能代码，不将重新编译等同于再次完成所有实机项目。

安装专项分别验证独立版、ASI 与公共 Loader，覆盖旧版迁移、无收据的分发切换、手动／脚本混用、未知文件拒绝、其他插件保留及路径链接。Windows 自带 PowerShell 5.1 的解析兼容单独检查，不能仅凭 PowerShell 7 执行成功判断玩家环境可用。

诊断探针没有第二套界面或输入挂钩，也不随玩家包分发。完整步骤和已测／未测组合见 [插件共存验证](PLUGIN_TESTING.md)，玩家安装步骤见 [ASI 与 Loader 指南](ASI_LOADER.md)。

## 全传送逻辑与行程回归

- **独立验证两种策略。** CMake 为已有保守规则和运行时测试显式定义 `SKY2_UNRESTRICTED_TRAVEL=0`，为 `_unrestricted_tests` 显式定义 `1`。正式 DLL 默认全传送，不应使保守测试悄然换成另一套预期。剧情限制策略检查登记、最终禁用、area、已审查旧图门槛及前置脚本；全传送策略验证这些目的地剧情条件不再拒绝公开清单目标。
- **核对完整目录及隐藏记录。** 本机目录包含 155 个原生目的地、迷途之森入口和返程，共 157 项、16 页，每页最多 10 项，末页 7 项。11 个纯内部 ID 不展示；公开城市 ID 的原生入口变体按当前地形选择，无匹配时采用原生首条回退。四塔完整“异空间”名称和“旧校舍地下遗迹 / 入口”不改变 ID、排序或落点。
- **保留实际身份与加载边界。** 覆盖主地点与当前道路地形使用不同 ID／variant、根候选歧义、当前地形不匹配、捕获失败清除 readiness、无效 scene／坐标和过期请求。12 个跨图 ID 的菜单 place 与目标 scene 不同，须通过真实目标 scene 的唯一默认根确定到达地区，不能用菜单地区或最近地点猜测。战斗、对话、演出、加载及非稳定浏览状态仍不能提交。
- **记录先于首次出发。** 验证记录写入失败拒绝派发，连续传送和步行不覆盖最初位置，精确返程恢复坐标与朝向，返程确认到达才结束会话；到达超时保留出发点并解除等待。历史记录不绑定存档槽位，必须让用户核对地点和时间；切到另一合法章节结束旧会话，同章普通开箱不能误清记录。
- **限定特殊事件保护。** 全传送实际提交后才启用 7 个特殊箱、40 个森林事件盒的行程保护；队列、取消和失败不能误开。连续传送保留许可，精确返程加载原场景前关闭，拒绝加载时恢复先前状态。保护与原生上下文读取直接核对章节令牌，隐藏面板后换章仍失效，读回旧章不能复活；普通主线、其他事件和未审核宝箱不应被全局禁用。
- **恢复和森林边界。** 重启不按历史自动恢复行程保护，不自动传送。同进程同章切档无法可靠识别，须先返程或退出重启。第 8 章序章无记录的柏斯兼容出口在全传送策略下仍先捕获并持久化出发点；剧情限制对照策略保留旧免记录路径。已有历史的第 8／9 章旧图恢复需先核对返程，不能覆盖原记录。迷途之森没有普通出口，首次验证应进入后立即返程，再测试开箱。

生产 helper 用例只访问测试进程自行分配的内存，MASM 测试直接链接生产汇编。它们不能证明真实地图碰撞、事件或所有剧情状态都已验证。每个新增实测记录应注明具体章节、目的地、往返结果及是否开箱，不把单个成功点扩大为全目录通过。

## 0.3.2 起的实机验证范围

在 README 指定的 Steam EXE、原生 D3D11 和 Xbox ABXY 布局下，已确认：

- 游戏正常启动、中文面板、区域地图中的未发现宝箱标记。
- 本周目与继承记录的计数和图标切换，读取存档后的状态回退。
- 完整地图前缀、两组地区计数、清单遗漏筛选与分页。
- View + RS 暂停／恢复有效且不弹出 Xbox 窗口。
- 组合键不会同时触发已验证场景中的原生操作，单独 View 保留原用途。
- 键鼠／手柄提示热切换、手柄断开重连。

尚未逐箱走访全部目标，未全面测试所有章节、楼层、其他手柄、自定义键盘模拟布局及其他图形注入工具。
成就是否解锁以游戏自身规则为准。

## 修改后的验证建议

输入修改重点检查单按、长按、先松修饰键、先松功能键及前后台切换；测试时确认使用的确实是新 DLL。
统计修改重点检查同一箱“本周目未开但继承已开”的情况，以及读旧档后能否回退。
绘制修改检查中文、完整路径、小窗口换行、页脚和两组地区计数是否完整可见。
