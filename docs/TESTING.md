失败用例同时断言拒绝原因和目录内容不变，避免其他前置错误导致假通过。
Windows CI 自动运行这些用例；非 Windows 环境明确跳过，没有创建符号链接权限时仅跳过对应链接用例。
这些测试不证明第三方 Mod 的运行时兼容，也不覆盖其他程序并发替换文件的情况。

## 0.3.2 实机验证范围

在 README 指定的 Steam EXE、原生 D3D11 和 Xbox ABXY 布局下，已确认：

- 游戏正常启动、中文面板、区域地图中的未发现宝箱标记。
- 当前周目与继承记录的计数和图标切换，读取存档后的状态回退。
- 完整地图前缀、两组地区计数、清单遗漏筛选与分页。
- View + RS 暂停／恢复有效且不弹出 Xbox 窗口。
- 组合键不会同时触发已验证场景中的原生操作，单独 View 保留原用途。
- 键鼠／手柄提示热切换、手柄断开重连。

尚未逐箱走访全部目标，未全面测试所有章节、楼层、其他手柄、自定义键盘模拟布局及其他图形注入工具。
成就是否解锁以游戏自身规则为准。

## 修改后的验证建议

输入修改重点检查单按、长按、先松修饰键、先松功能键及前后台切换；测试时确认使用的确实是新 DLL。
统计修改重点检查同一箱“本周目未开但继承已开”的情况，以及读旧档后能否回退。
绘制修改检查中文、完整路径、小窗口换行、页脚和两组地区计数是否完整可见。

报告问题时给出版本、EXE 哈希、设备布局和操作步骤。日志只需附与问题相关的几行，并删去不希望公开的信息。
