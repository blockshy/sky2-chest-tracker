## 手动测试准备

1. 备份游戏存档、当前 Mod 二进制、日志与返程记录，保存到游戏目录外。
2. 完全退出游戏，移走其他 Mod，只保留本次宝箱构建。ASI 测试保留其必要公共 Loader。
3. 核对安装文件哈希、面板版本、游戏 build，并记录本次启动时间，避免把旧日志当作新结果。
4. 从正常流程地点的测试存档开始。玩家操作输入时，日志核对方不同时发送按键或手柄输入。

## 游戏内检查

| 项目 | 操作与观察 |
| --- | --- |
| 初始化 | 面板出现；日志确认新 EXE、输入桥、地图、回访和局部保护均就绪 |
| 宝箱 | 切换本周目／继承记录，查看当前地图和全局计数、遗漏清单与图标 |
| 探索 | 区域地图内切换全显及未到访传送点，检查即时刷新、原生灰态与正常关图 |
| 输入 | 键盘／Xbox 手柄切换、组合键单次响应、翻页；需要时测试断开重连 |
| 普通传送 | 打开稳定区域地图，双次确认一处目标，观察到达而非仅看到提交日志 |
| 精确返程 | 返回出发场景，核对位置、朝向及成功到达日志 |
| 特殊场景 | 迷途之森入口、局部事件保护与返程；不将单个地点通过扩大为全流程通过 |
| 读档／重启 | 核对记录地点、时间与章节；旧 build 的历史文件保持不变 |
| 语言与显示 | 当前文字语言、必要字体、清单名称及缩放正常 |

测试过程中保留具体场景、章节、操作和时间。传送日志必须区分请求、原生交接、加载状态和最终到达；拒绝或超时需要结合当时操作判断，不能只按关键词统计异常。
