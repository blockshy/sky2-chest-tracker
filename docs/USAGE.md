## 按用途选择功能

| 想做什么 | 使用功能 | 作用 |
| --- | --- | --- |
| 在地图上找遗漏宝箱 | 宝箱标记 | 使用原生地图箱标，按当前显示模式区分已开／未开 |
| 判断哪些地图没有收集完 | 各地图宝箱收集 | 显示完整“大地图 / 地点”路径、两组计数和剩余未开数量，可筛选遗漏 |
| 看清当前地图的未探索区域 | 地图全显 | 临时显示已加载／选中地图的未探索分块 |
| 在游戏原生菜单中显示未到访地点 | 未到访传送点 | 按当前地区的原生菜单许可临时补显，保留原生禁用条件 |
| 跨地区或返回流程中已无法进入的地图 | 全传送清单 | 不以剧情或到访记录限制清单内地点，并记录首次出发点供精确返程 |

“未到访传送点”与“全传送清单”是两个独立功能。前者调整游戏自己的传送菜单，后者使用 Mod 的独立清单；开关前者不会改变后者的范围。

## 语言与字体

独立版与 ASI 版均支持游戏的**全部八种文字语言**，自动跟随游戏设置中的**文字语言**。在游戏内确认文字语言后，Mod 会自动更新界面和地点名称，无需单独设置；切换语音、Steam 客户端或 Windows 的语言不会改变 Mod 的选择。

| 游戏文字语言 | Mod 显示语言 |
| --- | --- |
| 简体中文 | 简体中文 |
| 日本語 | 日文 |
| English | 英文 |
| 繁體中文 | 繁体中文 |
| Deutsch | 德文 |
| Français | 法文 |
| Español | 西班牙文 |
| 한국어 | 韩文 |

本页以中文界面名称说明操作。八种语言的快捷键、宝箱统计与传送规则相同；切换语言不会改变目的地身份、清单导航位置或已有返程记录。地图、地区与传送地点使用对应语言游戏资源中的名称，不自行翻译专名；相同地点在不同语言下不一定能逐字对应。

八语文本已编入 DLL／ASI，不新增语言配置或翻译文件。字体使用本机 Windows 已安装的字体，不分发游戏或系统字体。若中日韩文字出现方框、缺字或字体缺失提示，请安装 Windows 对应的简体中文／繁体中文／日文／韩文补充字体后重启游戏。修改游戏语音语言或重新复制 Mod 无法补齐缺少的字形。

若文字语言切换后面板仍未跟随，请先确认安装了当前八语构建，而非同为 0.6.0 的旧包，再核对游戏内的文字语言设置。按 [安装指南](INSTALLATION.md#开始前) 使用配套哈希区分构建。

## 宝箱标记与统计

左侧导航栏底部固定显示“显示模式”，每次启动默认为**本周目**。点击对应模式可改为**继承记录（多周目）**，也可使用统计口径快捷键（默认 F6／View+X）。此处不随页面内容滚动，其他页面不重复放置模式切换控件：

- **闭合箱标：未开。**当前显示模式下尚未开启。
- **开启箱标：已开。**当前显示模式下已经开启。

标记包含对应区域中尚未发现的宝箱。“继承记录”模式把当前存档继承的记录与本周目新开的宝箱一同计入；因此，以前周目已开、本周目未开的箱子，在两种模式下可以显示不同图标。

| 面板文字 | 含义 |
| --- | --- |
| 本周目已开 | 当前存档本周目打开的宝箱 |
| 继承记录已开 | 当前存档继承的记录，并计入本周目新开的宝箱 |
| 本周目当前地区已开 | 当前地区的本周目计数 |
| 继承记录当前地区已开 | 当前地区的继承记录计数，包含本周目新开的宝箱 |

切换显示模式只改变箱标、剩余未开数量和遗漏筛选的依据，两组统计始终独立显示。打开区域地图后可查看当前地区计数。
继承记录只来自**当前读取的存档**，不会合并机器上的其他存档；读取旧档后，统计随该存档回退。

收集清单包含 **59 个地图分组、566 个正式宝箱**，使用“大地图 / 地点”完整名称定位。当前地区统计可能包含相邻道路，而清单将道路分别列出：例如卢安外围地区共 26 箱，阿伊纳街道单独统计 3 箱。迷宫计数包含各楼层，同名古罗尼山道区分柏斯／卢安。

没有宝箱的地图不列入收集清单，尚未到达的地点也会显示；有标记或统计不代表正常剧情已能进入。宝箱标记不替玩家开箱，不直接修改物品或宝箱记录，成就仍由游戏判定。

## 宝箱快捷键

以下列出当前独立版六项动作的**默认**快捷键，可在左侧“快捷键”栏目修改。

| 功能 | 键盘 | Xbox 手柄 | 功能条件 |
| --- | --- | --- | --- |
| 打开／关闭独立窗口 | 裸 F7 | View + 十字键上 | 输入桥与界面可用；窗口已打开时也能关闭 |
| 切换本周目／继承记录 | F6 | View + X | 切换统计口径，不修改宝箱记录 |
| 暂停／恢复宝箱地图标记 | 窗口内设置 | View + RS | 仅切换宝箱标记，不改探索辅助 |
| 地图全显开／关 | Ctrl + F6 | 窗口内设置 | 地图全显功能已成功初始化 |
| 未到访传送点开／关 | Ctrl + F8 | 窗口内设置 | 传送菜单功能可用；可能等待原生安全刷新 |
| 打开全传送页 | Ctrl + F10 | 从窗口左侧进入 | 只打开页面；实际传送另需区域地图和两次确认 |

开关窗口和统计口径快捷键在宝箱窗口内也可使用；统计口径快捷键在编辑文字或快捷键设置时暂停，避免一次编辑意外改变统计。其他业务直达键只在所有合作 Mod 窗口关闭时生效。窗口内通过控件筛选、分页和设置，不会把一次 A 确认同时解释成旧的清单快捷键。

默认 F7 仅接受没有 Ctrl、Shift、Alt 或 Win 修饰的单键。F8 / View+A 的清单直达入口已移除，清单改从窗口顶部页签进入；Ctrl+F8 的探索辅助仍保留。快捷键需要游戏处于前台、窗口渲染正常，并在初始化或返回前台后先松开旧按键。

默认 View+上必须精确匹配 View 与上方向，斜方向或额外数字按钮不会开窗。旧 View+B 开窗、F9 暂停（包括 Ctrl+F9、Shift/Alt/Win+F9 及其组合别名）、View+上全显和 View+下未到访已停用，以优先使用三个独立窗口的新入口。裸 F10、PgUp/PgDn、Ctrl+F7 和旧全局传送确认不会在窗口关闭时执行宝箱业务。

所有动作现在精确匹配已保存的主键及 Ctrl/Alt/Shift 修饰组合；旧的 Shift+F6、Ctrl+Alt+F6 等偶然别名不再触发默认动作，Win 组合不作为 Mod 快捷键。若需要不同组合，请在设置中明确选择并保存。

### 修改快捷键

在左侧“快捷键”栏目选择动作，再从列表选择键盘主键、修饰键和手柄按钮。手柄始终为 View＋一个按钮，不能占用无修饰的方向、确认或摇杆滚动。窗口入口必须保留一个键盘快捷键；普通业务动作允许清空绑定。

保存会检查本 Mod 及当前已加载的合作 Mod，冲突时提示占用的模块／动作并拒绝保存，不会顶掉另一项绑定。游戏本体、未加载的 Mod 和未接入协议的第三方 Mod 不在自动检查范围内。启动读取到冲突或损坏设置时会提示并使用可用回退；窗口入口会保留可打开的键盘组合。恢复默认也遵守相同冲突限制。

保存成功后立即使用新设置，并等待所有按键释放才重新触发。保存失败保留原实际绑定；离开栏目会撤销尚未保存的候选。配置位于 ASI 的 `plugins/Sky2ChestTracker/shortcuts.ini` 或 Standalone 的 `Sky2ChestTracker/shortcuts.ini`，重启后保留。

配置损坏或手工修改造成冲突时，启动会尝试恢复可用入口，并把最终的 `Window shortcut` 写入同目录的 `tracker.log`。默认按键打不开窗口时，先查该日志中的恢复提示；共享快捷键注册失败时不会启用宝箱挂钩。

| 窗口内操作 | 键盘 | Xbox 手柄 |
| --- | --- | --- |
| 选择内容 | 方向键 | 十字键／左摇杆 |
| 确认或编辑 | Enter | A |
| 退出编辑／关闭窗口 | Esc | B |
| 切换左侧用途分组 | PageUp / PageDown | LB / RB |
| 切换顶部页签 | Ctrl + PageUp / PageDown | LT / RT |
| 滚动当前内容或只读统计框 | 鼠标滚轮；方向键到边界继续 | 右摇杆 |

黄色焦点只在具体功能内容中。左侧分为“宝箱追踪”“功能设置”“传送与返程”“快捷键”；上方页签分别是“概览／清单”“功能开关／HUD 显示”“传送／返程”。快捷键栏目直接显示动作与编辑器。左侧底部的模式按钮可用鼠标点击，手柄通过统计口径组合键切换，不必把光标移出内容区。标题、简介、页签和底部提示固定，只有中间内容滚动。鼠标拖动窗口顶部标题可移动窗口。

“宝箱追踪 → 概览”显示收集进度；地图列表统一从顶部“清单”页签进入。宝箱标记开关位于“功能设置 → 功能开关”，概览不再重复显示整块标记设置。

首次启动显示简洁 HUD，完整窗口默认关闭。HUD 后续使用保存的显示设置。关闭窗口不改变标记或探索辅助；暂停标记只恢复原版地图图标。所有页面仍共用当前存档快照，窗口不会暂停游戏。

### HUD 内容与位置

打开“功能设置 → HUD 显示”，可分别选择标题、统计口径／暂停状态、当前统计地区名称、当前地区收集数量和全局收集数量。没有地区统计时，地区数量沿用原行为退回全局总数；同场景包含多个地点时不会冒充精确地点名。页面显示预览，HUD 总开关关闭时也能调整预览。

选择“调整位置”，再用鼠标拖动 HUD；松开鼠标保存位置，Esc/B、关闭窗口、离页或切出游戏取消尚未完成的拖动。“重置位置”恢复原来的左下锚点。主窗口必须处于前台并已取得输入控制；普通游戏过程中的 HUD 始终鼠标穿透，不接管游戏点击。

位置以屏幕相对坐标保存，改变分辨率后会限制在可见范围内。ASI 使用 `plugins/Sky2ChestTracker/hud.ini`，Standalone 使用 `Sky2ChestTracker/hud.ini`；只保存显示项目和位置，不保存统计数量、不修改游戏存档或探索开关。保存失败会明确提示并提供“重试保存”，当前选择可继续在本次运行使用。

## 探索辅助

| 功能 | 键盘 | Xbox 手柄 |
| --- | --- | --- |
| 地图全显开／关 | Ctrl + F6 | 窗口内设置 |
| 未到访传送点开／关 | Ctrl + F8 | 窗口内设置 |

两个开关均默认关闭，重启后关闭，宝箱标记的暂停／恢复不影响它们。面板将名称与实际状态一起显示，例如“地图全显：已关闭”。未打开区域地图时可先设置未到访传送点，再点击“打开地图并应用”；Mod 请求原生开图，首次构建清单即采用最新开关。地图已有确认窗口或处于过渡时，仍需等待回到浏览状态。

**地图全显**只影响原生当前加载或选中地图的未探索分块，保留楼层选择、淡入淡出和脚本禁用限制。它不会补充剧情尚未提供的地图目录，也不保证所有隐藏图标都出现。关闭后，未实际探索的分块恢复隐藏。

**未到访传送点**自动枚举当前地区的原生传送记录：目的地已被游戏登记、最终未被禁用，且所属分组未被禁用时，可以在尚未到访的情况下临时显示，必要时同时显示其地点分组。它没有固定点位数量，不要求先到访城镇或道路锚点；原生静态条件、内部点和特殊标识过滤仍然保留。

此开关采用的是**原生菜单许可**，不等于完整剧情可达判断，显示的地点仍可能越过入口剧情、物理障碍或迷宫层级。确认窗口和传送前后脚本继续由游戏执行。全传送清单另行提供不受这些目的地剧情条件限制的入口，见 [全传送指南](TRAVEL.md)。

开关在区域地图、全地点列表及城镇／道路子列表的浏览阶段原地生效，无需关图重开。确认弹窗或转场期间会等待返回浏览阶段后应用。刷新保留地图镜头和缩放；临时选中项消失时，游戏重新选择有效地点，列表滚动位置可能重置。切换后当前子列表或整个原生传送清单合法为空时，地图会正常关闭，功能仍可继续使用。

Mod 不把这些临时显示批量写成探索或到访记录；实际行走、传送和自动保存仍可能记录真实进度。关闭辅助不会撤销已经完成的探索。详细回归步骤见仓库中的 [探索辅助测试指南](https://github.com/blockshy/sky2-chest-tracker/blob/main/docs/EXPLORATION_TESTING.md)。

## 全传送入口

在自由行动时按 `Ctrl + F10`，或打开独立窗口进入“传送与返程”。未打开区域地图时，先点“准备传送 / 准备返程”，等待游戏打开原生地图；已稳定浏览地图时可直接操作。“传送”页包含 155 个原生地点和迷途之森补箱入口，“返程”页独立管理精确返程。准备操作不会自行传送，原生地图仍会显示。View + 十字键左现在用于队伍编辑窗口。

选择目的地后需两次独立确认；连续传送保留最初的出发位置与朝向。使用前保留独立存档，切档前先返程或退出重启；返程记录不绑定存档栏位，原生剧情和自动保存仍会运行。

完整键位、前往／返回步骤、特殊地点位置及重启后的历史选择见 [全传送指南](TRAVEL.md)。

0.6.0 插件版使用独立的 `plugins/Sky2ChestTracker/` 数据目录，首次没有独立版的返程历史，也不会自动导入。切换分发前先在原版本完成返程或准备正常流程地点的存档；旧日志和返程记录保留在 `Sky2ChestTracker/`。迁移步骤见 [ASI 指南](ASI_LOADER.md)。

## 手柄与输入切换

**View 是双窗口键；LS／RS 表示按下摇杆，左／右摇杆表示拨动。**先按住 View，再按组合键；单独点击 View 仍打开游戏原生地图。开窗组合、关闭后仍按住的按钮和摇杆会等待释放，不额外传给游戏一次攻击或确认。

独立 ASI 在游戏自己的 XInput 调用链观察 Steam Input 映射结果，不另行轮询物理设备。三个合作 Mod 共享输入所有权：打开另一个窗口时，旧窗口关闭并保留位置／页签。宝箱是 `F7` / `View + 十字键上`，队伍编辑是 `F8` / `View + 十字键左`，交互高亮是 `F9` / `View + 十字键下`。三个窗口键均精确匹配裸功能键，Ctrl+F8 不会打开队伍窗口。

切出游戏时保留只读窗口、立即撤销传送确认并释放输入；返回后须松开旧按键再继续。渲染停止超过 500 毫秒也会放行输入。独占全屏最小化时，窗口随游戏停止绘制。

跨显示器或更改缩放后，鼠标位置按游戏窗口的 DPI 重新换算；实际移动鼠标可从手柄切回。游戏重建窗口或图形设备时，Mod 重新绑定输入和绘制资源，保留业务页与窗口显示意图，撤销未完成确认。恢复前台后先松键再操作；不同显示器和全屏模式的实际组合需在本机确认。

## 清单位置与面板显示

宝箱页码、传送目标、各分组上次子页和窗口位置在本次进程内记忆。关闭窗口、切换分组或切出游戏不会保留传送授权，重新操作仍须两次确认。调整分辨率后窗口会限制在客户区内。

宝箱清单按游戏目录中的固定地区顺序归组，同地区保持原目录顺序；开启／关闭遗漏筛选、改变收集数量或切换显示语言不会重新排列地区。筛选或显示模式变化后，宝箱清单回到第一页；数据暂时不可用时保留浏览位置。传送列表可搜索，搜索隐藏当前目标时禁止确认旧目标，须重新选择或清空搜索。

## 常见问题

- **没有面板：**先按 F7／View + 十字键上 检查是否只是隐藏。仍未出现时，按 [安装指南](INSTALLATION.md) 核对完整安装包、游戏版本、DLL 位置和日志；源码压缩包不能直接安装。
- **语言不对应或出现方框：**核对游戏的文字语言及当前构建哈希；缺少字形时安装相应 Windows 补充字体，见 [语言与字体](#语言与字体)。
- **继承图标与本周目不同：**这是预期行为。以前周目已开的宝箱，本周目可能尚未开启；继承统计不会合并其他存档。
- **地区计数与清单中的道路计数不同：**地区可能合并相邻道路，清单逐条列出道路，迷宫则包含各楼层。
- **宝箱图标恢复成原版：**检查是否显示“宝箱标记已暂停（原版显示）”，在设置页恢复，或关闭窗口后按 View + RS 恢复。
- **手柄组合不响应：**切回游戏并松开全部控制，再先按 View 后按功能键；RS 要按下，肩键与扳机用途不同，并检查 Steam Input 是否保留 View 输出。
- **开启未到访传送点后没有新增地点：**当前地区可能没有符合原生许可的未到访点，或仍在等待确认／转场结束；这不等于全传送清单不可用。
- **开关传送辅助后地图自动关闭：**合法空列表会正常关图，重新打开即可继续操作。若面板同时显示“不可用”，请保留操作时间附近的日志，说明当时的列表层级。
- **全传送无法确认或重启后需要返程：**先打开稳定的区域地图，按面板具体原因处理；历史返程须自行核对地点与时间，详见 [全传送常见问题](TRAVEL.md#常见问题)。
- **同名 DLL 冲突、手动／脚本混用或执行策略阻止脚本：**按 [安装指南](INSTALLATION.md) 核对文件归属及手动操作方式。不要覆盖未知 DLL、篡改归属记录，或为了运行脚本修改不允许更改的设备策略。

## 范围与问题反馈

原独立版的宝箱状态、读档回退、地区统计、清单、Xbox 组合键、热切换和重连已有实机验证；地图全显、未到访传送点及地图内即时刷新已有用户本机正常反馈。全传送已有一周目末期、二周目前期相关地点及往返反馈，不能代表全部地点和所有章节组合均已逐一验证。0.6.0 ASI 已在本机 Steam Input／Xbox ABXY 环境确认与诊断探针同时加载、清单操作、提示切换、重连及一次传送返程正常；其他实际 Mod 组合仍需单独验证，适用范围见 [ASI 指南](ASI_LOADER.md#故障排查与兼容范围)。

反馈问题时提供 Mod 版本、独立版／ASI 分发类型、游戏构建、地图／章节、输入设备、操作步骤及完整提示。独立版日志位于游戏目录的 `Sky2ChestTracker/tracker.log`，ASI 日志位于 `plugins/Sky2ChestTracker/tracker.log`；附相关片段前移除个人信息，无需公开整份存档或内存快照。
